# Sentiment Classifier from Scratch

My first AI/ML project. It reads a piece of text (like a movie review) and predicts whether it's **positive** or **negative**.

## What it does

1. Takes text input
2. Converts it into numbers using TF-IDF
3. Feeds it into a Logistic Regression model
4. Predicts positive or negative

## Why I built this

Starting my journey to become an AI engineer. This is project #1 — small, simple, and it works end to end.

## Tech used

- Python
- scikit-learn
- pandas

## How to run

```bash
pip install -r requirements.txt
python train.py
python predict.py "This movie was amazing!"
```
